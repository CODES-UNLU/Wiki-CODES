El **GitHub Student Developer Pack** es el beneficio estrella para carreras de informática: te da acceso gratis a montones de herramientas de desarrollo que normalmente se pagan, como **GitHub Copilot**, dominios, hosting, IDEs, créditos en la nube y más.

<LinkButton href="https://education.github.com/pack" icon="external">
	Solicitar el GitHub Student Developer Pack
</LinkButton>

## Cómo solicitarlo

1. Create una cuenta de [GitHub](https://github.com/) (o iniciá sesión si ya tenés).
2. Entrá al link del pack y tocá **"Sign up for the Student Developer Pack"**.
3. Completá tus datos: nombre de la universidad (**Universidad Nacional de Luján**), explicá con tus palabras qué estudiás y con qué vas a usar las herramientas.
4. **Evidencia de que sos estudiante**: subí tu **Certificado de alumno regular** de la UNLu, que se descarga desde el **Perfil de Estudiante**.

<LinkButton href="https://saweb.unlu.edu.ar/academica/estudiante-index.php" icon="external">
	Ir al Perfil de Estudiante (UNLu)
</LinkButton>

:::note
Como la UNLu no está conectada con GitHub Campus, la verificación es manual: revisan la solicitud y la documentación que subas.
:::

## Esperar la aprobación

- La revisión puede **demorar unos días** (a veces semanas).
- Cuando te aprueban, te llega un **correo de GitHub** confirmando la habilitación.
- Después podés activar los beneficios desde la [página del pack](https://education.github.com/pack), como GitHub Copilot Pro gratis.

<Aside type="note">
	**GitHub Copilot está con cuota limitada.** Hoy el plan de estudiante trae una cantidad reducida de usos por mes y en los chats solo el modelo **Auto** (Google elige el modelo automáticamente, no podés elegir otro). Igual sirve para arrancar y se complementa con el resto del pack.
</Aside>
