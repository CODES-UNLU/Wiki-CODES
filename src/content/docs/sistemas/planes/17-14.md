## Datos de la carrera

| Dato | Valor |
| ---- | ----- |
| Título de Grado | Pregrado: Analista Programador/a Universitario/a · Grado: Licenciado/a en Sistemas de Información |
| Duración | 5 años |
| Inicio | 2025 |
| Régimen | Cuatrimestral (16 semanas) |
| Modalidad | Presencial |
| Hs. totales | **3374 hs** (Analista: 1888 hs · Licenciatura: 1486 hs) |
| Ingreso | Título nivel medio o mayores de 25 años (Art. 7 Ley 24.521) |
| Coordinadora | Dra. Gladys Kaplan ([coor-sistemas@mail.unlu.edu.ar](mailto:coor-sistemas@mail.unlu.edu.ar)) |

- **Analista Programador/a:** 22 actividades académicas + 2 acreditaciones de competencias.
- **Licenciado/a:** 16 actividades + Optativas (150 hs) + Prácticas Socio-Técnico-Culturales (80 hs) + Tesina de Grado.

## Notas

1. Las **Competencias Básicas** de idioma e informática deben acreditarse para iniciar el tramo de Licenciatura.
2. El **Taller Introductorio** se dicta entre octubre y diciembre (formato no intensivo), o en formato intensivo en febrero.
3. Las **optativas** se cursan hasta completar 150 hs.
4. Aprobando ciertas actividades se accede a las **Diplomaturas Intracurriculares** ([Res. H.C.S. 726/24](https://www.planesdeestudio.unlu.edu.ar/sites/www.planesdeestudio.unlu.edu.ar/files/site/17-SCAN/RES%20HCS%20726-24.pdf)). Certificación: [titulos@unlu.edu.ar](mailto:titulos@unlu.edu.ar).
