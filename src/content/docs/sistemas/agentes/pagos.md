Acá está lo que **no tiene versión gratuita útil**: si no querés poner plata, quedate con [Antigravity](../antigravity/), [opencode](../opencode/) o lo que regala el [GitHub Student Pack](/unlu/beneficios/github-students/). Como regla, por debajo de **USD 20 al mes** las cuotas no alcanzan para nada serio, con **una sola excepción**: el Go de opencode, que por USD 10 rinde.

Si vas a gastar, esto es lo que recomendamos:

## opencode Go (USD 10) — preferido

Si vas a poner plata en agentes, **preferible gastar acá**: por **USD 10** el [opencode Go](../opencode/) da acceso a bastante IA y a los **modelos chinos nuevos**, es **open source**, se paga menos que cualquier alternativa seria y encima es el que más rinde por peso. Si todavía no lo activaste, hay un [enlace de referido](../opencode/#enlace-de-referido) que les da USD 5 de crédito a los dos.

:::tip
Recordá activar los **modelos alojados en China** en la pestaña de Go: vienen desactivados por defecto.
:::

## Claude Code

El agente de Anthropic, y el que suele ganar cuando el trabajo es **leer y reescribir código a través de muchos archivos**. Punto importante: **no tiene plan gratis** (a diferencia de Copilot o Gemini CLI): pagás desde el día uno.

- **Pro (USD 20/mes)**: entrada al plan, incluye Claude Code.
- **Max (USD 100 o 200/mes)**: 5x o 20x de uso, para quien lo usa como herramienta principal.

Si el trabajo es puramente código, Claude Code es la apuesta más fuerte de la lista.

## Cursor Pro

Y sí: si querés **una buena cantidad de tokens**, pagar **Cursor Pro (USD 20/mes)** no es tan mala idea jaja. Seguís usando el editor con el agente adentro, con cuotas mucho más generosas que el plan gratuito, y sin cambiar de entorno si ya te gustó [Cursor](../cursor/).

## ChatGPT Codex (y por qué no pagar el Go)

El agente de OpenAI viene incluido en los planes de ChatGPT. El consejo fuerte es este:

:::caution
**Nunca pagues el plan Go de ChatGPT para esto.** El Go es una cagada jaja: es el plan barato y para programar no te alcanza ni para empezar. Si vas a poner plata, **pagá desde Plus (USD 20/mes) para arriba**. Y ojo: Plus te da Codex con cuotas chicas, para programar en serio rinde menos que Claude Code o Cursor Pro por la misma plata. El salto de verdad de Codex está en **Pro (USD 100 o 200/mes)**, con 5x o 20x de uso.
:::

Si querés Codex y no querés pagar, usá lo que ya viene con las cuotas gratuitas de ChatGPT. Si vas a pagar, hacelo **desde Plus**, nunca desde Go.

## Resumen

| | Gratis | Entrada paga | Cuándo conviene |
| --- | --- | --- | --- |
| opencode Go | Modelos de uso gratuito | USD 10 | **Preferido**: el mejor rinde por peso, open source y con modelos chinos |
| Claude Code | No | Pro, USD 20 | El trabajo es leer/reescribir mucho código |
| Cursor Pro | Plan gratuito cortito | USD 20 | Ya te gustó Cursor y querés más tokens |
| ChatGPT Codex | Con ChatGPT Free (muy limitado) | Plus, USD 20 (**nunca el Go**) | Querés además todo el ecosistema ChatGPT |

:::tip
Antes de pagar, agotá lo gratis: Antigravity sale **gratis** con el plan Google AI Plus de estudiante y opencode tiene modelos de uso gratuito. Cuando pagues, **preferí opencode Go**; si querés algo más pesado, Claude Code o Cursor Pro (USD 20) y, si querés ChatGPT, desde Plus. El **Go** de ChatGPT no, ni lo mires.
:::
