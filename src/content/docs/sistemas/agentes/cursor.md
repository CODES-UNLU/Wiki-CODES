title: Cursor

---

[Cursor](https://cursor.com/es/home) es **otro editor de código, distinto**, que recomendamos por su agente: un IDE completo construido "IA primero" (basado en VS Code, así que te llevás extensiones, atajos y configuraciones de tu VSCodium/VS Code casi tal cual). El agente lee todo el proyecto, propone cambios multiarchivo y los podés revisar en diffs antes de aceptar.

Diferencias clave con [Antigravity](../antigravity/): en Cursor el agente vive **adentro del IDE** (similar al Antigravity IDE standalone, pero más pulido y maduro), mientras que Antigravity 2.0 es una app aparte para orquestar varios agentes. Si ya usaste [VS Code](../../editores-recomendados/), Cursor te resulta familiar el primer día.

:::caution
Cursor **no tiene beneficio estudiantil**: no da nada gratis por ser estudiante (el [GitHub Student Developer Pack](/unlu/beneficios/github-students/) tampoco incluye Cursor). Su **plan gratuito** tiene límites bastante cortitos, así que alcanza para probarlo y ver si te gusta, pero no para el día a día; el Pro es pago. Igual está lindo para probar. No confundas esto con Antigravity, que sí te corre con el plan Google AI Plus.
:::
